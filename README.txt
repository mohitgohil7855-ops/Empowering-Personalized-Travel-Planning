GlobeTrotter Web Application Template
=====================================

Files:
- index.html  -> application structure
- styles.css  -> responsive color theme, cards, animations
- app.js      -> navigation, live preview, image upload, date validation and localStorage

Run:
1. Keep all 3 files in the same folder.
2. Open index.html in a browser.
3. For best development workflow, use VS Code + Live Server.

Current working screens:
- Dashboard
- Create Trip
- My Trips
- Itinerary placeholder

Create Trip functionality:
- Trip name
- Start/end dates
- Description
- Cover image preview
- Live preview card
- Date validation
- Save trips to browser localStorage
- Responsive desktop/tablet/mobile layout

This is a frontend template; backend/database/API can be connected later.
